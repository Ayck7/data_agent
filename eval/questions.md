# 评测问题集（Eval Set）

> 目的：**"能跑通"不等于"答案对"。** 用同一组问题对比不同版本，量化改进效果。
> 最新一轮：2026-09-25（M3）

## 一、M2 → M3 对照结果（核心成绩单）

| 指标 | M2 | M3 | 变化 |
|---|---|---|---|
| **评测通过率** | 4 / 6 | **7 / 7** | +3 |
| 客户数提问 | ❌ 答"412 位客户" | ✅ 答"59 位"并注明来源列 | 修复 |
| 同题复问的 token（第 5 轮） | 5700 | **2230** | **↓ 61%** |
| 数据覆盖范围判断 | ❌ "共 50 个月 / 数据到 2025-02" | ✅ "共 60 个月 / 2021-01~2025-12" | 修复 |

**关键改动**（对应代码）：

| 改动 | 针对问题 |
|---|---|
| 工具返回结构化数据（`columns` + `row_count` + `truncated`） | 列含义误读、截断盲区 |
| 单次回灌最多 20 行 + 单元格截断 200 字 | 上下文膨胀 |
| 只保留最近 3 轮历史（按轮次成对保留） | 上下文膨胀 |
| 提示词新增 3 条自检规则（标明来源列 / 计数必须直接 COUNT / 歧义说明） | 数值误读 |

## 五、记录规范

每发现一个新问题，按这个格式追加到第二节：

```
| # | 问题原文 | 期望行为 | 标准答案（自己先查一遍） | 旧版本结果 | 新版本结果 | 判定 |
```

⚠️ **标准答案必须自己先用 SQL 查一遍**——评测的地基是"你知道正确答案是什么"。

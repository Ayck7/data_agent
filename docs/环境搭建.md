# 环境搭建（从零到跑通）

> 目标：一个干净的环境，从**空电脑**到能跑通 Agent、界面和评测。
> 全部命令在 **Windows PowerShell** 下验证通过；macOS / Linux 只需把路径换成对应写法。
> 碰到报错先看 [`05-常见问题FAQ.md`](05-常见问题FAQ.md)。

---

## 0. 前置条件

| 项 | 要求 | 检查命令 |
|---|---|---|
| 操作系统 | Windows 10/11（本项目实测） | — |
| Conda | Miniconda 或 Anaconda | `conda --version` |
| 网络 | 能访问 PyPI 镜像与 HuggingFace 镜像 | `ping pypi.tuna.tsinghua.edu.cn` |
| 磁盘 | 约 3 GB（torch 约占 2 GB） | — |

没有 conda？先装 [Miniconda（Windows 安装指南）](https://www.anaconda.com/docs/getting-started/miniconda/install/windows-cli-install)。

---

## 1. 创建独立环境

```powershell
conda create -n data_agent python=3.11 -y
conda activate data_agent
```

> **本项目实测环境**：Python 3.14.6（见 `requirements.txt` 注释）。
> 用 3.11 / 3.12 更稳（第三方包兼容性更好），两者都能跑。

**关键**：激活成功的标志是提示符前缀变成 `(data_agent)`。

```powershell
# 确认 python 与 pip 是同一个解释器（新手最常踩的坑）
python -c "import sys; print(sys.executable)"
```

---

## 2. 配置 pip 国内镜像（可选但强烈建议）

```powershell
python -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
python -m pip config set global.trusted-host pypi.tuna.tsinghua.edu.cn
python -m pip config set global.timeout 120
```

---

## 3. 安装依赖

```powershell
cd D:\data_agent
python -m pip install -r requirements.txt
```

> ⚠️ **必须写 `python -m pip`**，它强制使用当前环境的 pip，避免"装到别的 Python 里"。

验证：

```powershell
python -c "import openai, chromadb, streamlit, matplotlib; print('依赖 OK')"
```

---

## 4. 配置 API Key

```powershell
copy .env.example .env
```

用编辑器打开 `.env`，填入你的 Key：

```ini
DEEPSEEK_API_KEY=sk-你的真实Key
```

申请地址：<https://platform.deepseek.com/api_keys>

> **`.env` 已被 `.gitignore` 排除**，不会上传到 GitHub。
> 公网演示前，再取消注释 `DEMO_PASSWORD=...` 开启口令门禁。

## 6. 首次运行（会下载向量模型）

```powershell
# ① 先单测 RAG 检索模块：建索引 + 跑 3 个自测查询
python docs_rag.py
```

首次运行会自动下载 `BAAI/bge-small-zh-v1.5`（约 91 MB）。
代码已默认使用国内镜像 `hf-mirror.com`，并会在模型**已缓存时自动离线加载**（避免启动时联网校验卡住）。

**预期输出**：

```
[docs_rag] 索引 1 个文件 -> N 个片段 -> D:\data_agent\docs_chroma

=== 查询： 销售额怎么定义 ===
[1] 来源：数据字典.md（相似度 0.xxx）
**标准口径**：`SUM(Invoice.Total)` …
```

```powershell
# ② 跑 Agent
python m4_agent.py
```

```
你问> 消费最高的五位客户是谁？
```

---

## 7. 启动界面

```powershell
streamlit run app.py
```

浏览器自动打开 <http://localhost:8501>。若设置了 `DEMO_PASSWORD`，会先要求输入口令。

---

## 8. 跑自动化评测

```powershell
python eval/run_eval.py
```

约 1–3 分钟，输出 10 个用例的通过率，并生成：

- `eval/results.md` — 评测报告
- `eval/last_run_trace.md` — 完整回答与工具调用轨迹（供人工复核）

---

## 9. 可选：公网演示

```powershell
# 终端 1：跑应用
streamlit run app.py

# 终端 2：开隧道（需先安装 cloudflared）
cloudflared tunnel --url http://localhost:8501
```

终端 2 会打印 `https://xxxx.trycloudflare.com` —— 即公网演示地址。

> ⚠️ 演示前**务必**在 `.env` 中设置 `DEMO_PASSWORD`；演示结束后按 `Ctrl+C` 关闭隧道。
